
# ☕ Task Tracker - Backend

Backend da aplicação Task Tracker desenvolvido com Spring Boot.

## 🛠️ Tecnologias
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Swagger

## 📌 Endpoints
GET /api/tasks  
POST /api/tasks  
PUT /api/tasks/{id}  
DELETE /api/tasks/{id}

## ▶️ Executar
./mvnw spring-boot:run

Swagger:
http://localhost:8080/swagger-ui.html
