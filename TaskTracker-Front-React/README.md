
# ⚛️ Task Tracker - Frontend

Frontend da aplicação Task Tracker desenvolvido em React + Vite.

## 🛠️ Tecnologias
- React
- Vite
- TypeScript
- React Router DOM
- Recharts
- CSS

## ✨ Funcionalidades
- Listagem de tarefas
- Criação, edição e exclusão
- Alteração de status
- Dashboard com gráficos

## ▶️ Executar
npm install
npm run dev

Acesse: http://localhost:5173
