
# 📝 Task Tracker

O **Task Tracker** é uma aplicação full stack para gerenciamento de tarefas, permitindo criar, editar, excluir e acompanhar o status das tarefas (concluídas ou pendentes), além de visualizar um **dashboard com gráficos**.

## 🚀 Tecnologias Utilizadas

### Backend
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Swagger (OpenAPI)

### Frontend
- React
- Vite
- TypeScript
- React Router DOM
- Recharts
- CSS puro

## ⚙️ Funcionalidades
- CRUD de tarefas
- Marcar tarefas como concluídas ou pendentes
- Dashboard com gráficos
- Integração Frontend + Backend

## ▶️ Como Executar

### Backend
./mvnw spring-boot:run

### Frontend
npm install
npm run dev

Frontend: http://localhost:5173  
Backend: http://localhost:8080
